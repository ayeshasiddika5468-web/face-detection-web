# face-detection-web# 😊 Face Detection Web App

## 📌 Project Description

This project is a simple Face Detection Web Application created using
HTML, CSS, and JavaScript.

The application opens the user's webcam and detects faces in real time.
A box is displayed around each detected face.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Face-API.js
- Webcam / Camera

## 📂 Project Structure

Face-Detection/
│
├── index.html
├── style.css
├── script.js
└── README.md

## ✨ Features

- Opens the webcam
- Detects faces in real time
- Displays a box around detected faces
- Shows the number of detected faces
- Simple and user-friendly interface

## 🚀 How to Run

1. Open the project in Visual Studio Code.
2. Install the Live Server extension.
3. Open `index.html`.
4. Right-click on the file.
5. Select **Open with Live Server**.
6. Allow camera permission when asked.
7. The webcam will start.
8. The application will detect faces automatically.

## 📷 Camera Permission

The browser needs permission to access the webcam.
Click **Allow** when the camera permission popup appears.

## 📚 Library Used

This project uses **Face-API.js** for face detection.

Face-API.js uses a machine-learning model to detect faces from
the webcam video.

## 🎯 Output

The application displays:

**Camera ON - Detecting faces...**

and shows:

**Faces detected: 1**

when one face is detected.
